⚙️ إعدادات النشر والدومين والتحميل

🌐 1. ربط دومين خاص بك (Custom Domain)

إذا قمت بشراء دومين خاص من هوستينجر أو نيم شيب، أدخله هنا لربطه فوراً:

إعدادات الـ DNS المطلوبة في لوحة تحكم الدومين:
• Type: CNAME | Host: @ أو store | Target: cname.autocorp.io
• أو Type: A Record | Target: IP السيرفر
📦 2. تصدير حزمة استضافة هوستينجر (Hostinger Production Bundle)

حمّل الموقع كاملاً بملف ZIP جاهز للرفع على استضافة هوستينجر (Hostinger) أو أي cPanel في مجلد public_html.

🎨 3. تعديل بوابات الدفع وبيانات المتجر

🚀 النشر المباشر على GitHub & Vercel

سيقوم AutoCorp بإنشاء مستودع (Repository) في حسابك ورفع ملفات المشروع كاملة (index.html, server.js, package.json, vercel.json, README.md).

يتطلب صلاحية repo لإنشاء ورفع الملفات. إنشاء توكن

انشر موقعك على سحابة Vercel العالمية فوراً برابط مباشر وسرعة فائقة.

من لوحة Vercel: Settings -> Git -> Deploy Hooks
